# 🧠 JavaScript Quiz App

An interactive quiz application built with vanilla JavaScript that tests users with multiple-choice questions while tracking their progress and score in real time.

## 🚀 Overview

The JavaScript Quiz App provides an engaging way to answer a series of questions, receive immediate feedback, and view a final performance summary. The application focuses on DOM manipulation, state management, and dynamic rendering without relying on external libraries.

## ✨ Features

- Interactive multiple-choice quiz
- Dynamic question rendering
- Real-time score tracking
- Progress indicator
- Final results screen
- Restart quiz functionality
- Responsive design

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📦 Installation

1. Clone this repository

```bash
git clone https://github.com/BoiMezie/JS-Quiz-App.git
```
2. Open the project folder.
3. Launch the index.html in your browser
